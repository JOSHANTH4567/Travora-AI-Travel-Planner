# Travora - AI Travel Planner

## Overview

Travora is an Android-based AI-assisted travel planning application designed to help travelers plan personalized trips.

The application integrates authentication, itinerary planning, destination discovery, transport planning, weather information, hotel recommendations and restaurant recommendations.

---

## Features

- Google Authentication
- Firebase Authentication
- Firestore Integration
- Personalized Travel Planning
- Travel Style Selection
- Hotel Recommendations
- Restaurant Discovery
- Weather Information
- Itinerary Generation
